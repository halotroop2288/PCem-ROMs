# PCem-ROMs

This is a collection of PCem roms. 

## Getting started

1. Get PCem
   - The latest PCem release is [on the website](https://www.pcem-emulator.co.uk/downloads.html).
   - The latest snapshot is available [from GitHub actions](https://github.com/sarah-walker-pcem/pcem/actions). (You need to be signed in to GitHub)
   - To compile it from the source, clone or download the source from [the Git repository](https://github.com/sarah-walker-pcem/pcem).
2. [Download this repository](https://github.com/BaRRaKudaRain/PCem-ROMs/archive/refs/heads/master.zip) and extract it to the roms folder.  Now configure the emulator and enjoy.
